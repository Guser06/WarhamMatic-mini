Descripción:
Este es un programa que creé como una herramienta para hacer que el set inicial de la décima edición de Warhammer sea más fácil de jugar para los recién llegados al juego.
Te permitirá simular dos ejércitos y sus propiedades, movimientos, cargas y combates entre otras reglas básicas.
Básicamente, es una versión automatizada del libro de reglas del set inicial.
-Características-
En este programa podrás:
-Juega como Marines Espaciales o Tiránidos
-Decide qué jugador comienza el partido.
-Selecciona una variedad de acciones ordenadas para realizar con cada unidad.
-Encontrar datos sobre cada miniatura.
-Ganar cuando todas las unidades de un jugador esten derrotadas ó
-Ganar cuando hayan pasado 8 rondas
Esto puede permitirte jugar sin dados, hojas de datos y tal vez incluso sin el libro de reglas inicial.
-Desventajas-
Debido a la complejidad de las reglas no pude incluir mucho contenido, en esta lista de caracteristicas faltantes están:
-La fase de mando
-Estratagemas
-Choque de batalla (Acobardamiento)
-Reglas de destacamento
-Reglas de palabras clave
-Gran parte de las "reglas del costado de la hoja de datos" (No hay dolor, baliza de teletransporte, etc.)
-Armas opcionales

Description:
This is a program I created as a tool for making the Warhammer 10th edition starter set easier to play for newcomers in the game.
It´ll allow you to simulate two armies and their properties, movements, charges and combats among other basic rules.
So basically, its an automated version of the starter set rulebook.
-Features-
In this program you can:
-Play as Space Marines or Tyranids
-Find wich player begins the match
-Select a variety of ordered actions to make with each unit
-Find data about each miniature
-Finish the match whenever an army was completely destroyed or
-Finish the match when 8 rounds had passed
This may allow you to play without dices, datasheets and maybe even without the starter set rulebook.
-Downsides-
Due to the complexity of the rules, I wasn´t able to include a lot of content, in this list there are:
-The command phase
-Stratagems
-Battle shock
-Detachment rules
-Keyword rules
-A great part of the "side of the datasheet rules" (Feel no pain, teleport homer, etc.)
-Optional weapons
